I built a dashboard with outer Grid layout and inner Flexbox cards combining both technologies. I created a header at top with dashboard title and action icons, a sidebar on left with brand name and navigation links, and a main content area for statistics and tables, and used CSS Grid for the outer page by setting display grid on the dashboard container with grid-template-columns 240px 1fr for sidebar and main, grid-template-rows 65px 1fr for header and main, and grid-template-areas to place sidebar header on first row and sidebar main on second row. In the main area I added four statistic cards showing Total Users, Revenue, Orders, and Growth, each displaying an icon, percentage badge, title and number. For inner alignment, I used Flexbox inside each card: the card itself is display flex with flex-direction column and justify-content space-between, the top part card-top uses display flex with justify-content space-between and align-items center to align the icon box on left and badge on right, and the bottom part card-bottom uses flex column to stack title and number vertically, which demonstrates how Flexbox perfectly aligns icons, titles, and numbers inside Grid items. I added a small table section showing recent orders with columns ID, Customer, Amount, Status, and a recent activity section with dot indicators and timestamps, both placed using another grid bottom-grid with 2fr 1fr columns. I checked the layout using DevTools Grid inspector by opening Chrome DevTools, going to Elements, clicking the grid badge next to dashboard and stats-grid, which shows grid lines, track sizes, and gaps visually, confirming that outer layout uses Grid and inner card layout uses Flexbox, and I tested responsiveness where on tablet stats become 2 columns and on mobile 1 column with sidebar moving to top.
